# 확률 실험실

학생들이 직접 시행을 반복하며 큰수의 법칙을 관찰하는 한국어 정적 웹사이트입니다. 로그인이나 결과 수집 서버가 필요하지 않습니다.

## 실험

동전 던지기, 주사위 던지기, 윷 던지기, 두 주사위의 합, 원주율 추정, 몬티홀, 쿠폰 수집가, 2차원 무작위 산책을 제공합니다.

- 한 번 실행, 길게 눌러 기기 성능에 맞춰 가속 실행, 정지, 기록 초기화
- 추가 시행 횟수: 10⁷~10¹⁰ 지수 슬라이더, 기본 10⁸회
- 진행률, 실측 처리량과 예상 남은 시간
- 상대오차 0.1%·0.01%·0.001%의 첫 진입과 현재 유지 구간

오차 기록은 매 시행을 순서대로 확인합니다. 현재 계산은 정밀 순차 실행이며 다중 Worker 병렬 실행은 아직 적용하지 않았습니다. 범위에 진입한 뒤에도 다시 벗어날 수 있고, 진입 기록은 통계적 유의성이나 이후 정확도의 보장이 아닙니다.

10¹⁰회는 선택 가능한 상한이며 모든 기기에서 짧은 시간에 완료된다는 뜻은 아닙니다. 누적 시행은 정수 합계의 안전성을 위해 9×10¹¹회로 제한합니다. 새로고침하면 기록이 사라집니다.

## 실행과 배포

[실험실 열기](https://ray-math.github.io/probability-lab/)

공개 저장소의 index.html은 스타일과 JavaScript 모듈을 모두 포함하는 단일 배포 파일입니다. 모듈은 import map의 base64 data URL로 포함되며 외부 JavaScript 의존성이 없습니다. GitHub Pages는 main 브랜치의 루트를 배포합니다. 학생 로그인이나 서버 저장은 사용하지 않습니다.

최적화는 표시되지 않는 시행의 문자열·경로 객체 생성을 생략하고 쿠폰 수집 상태를 비트 집합으로 관리합니다. 원래 모형과 같은 난수 소비 순서, 누적합, 빈도, 차트 점, 최근 결과 및 매 시행 오차 기록이 일치하는 테스트를 통과했습니다. 몬티홀 진행자도 동일한 규칙과 난수 순서를 유지하며 임시 배열만 제거했습니다. 전체 테스트 64개 통과.

같은 개발 기기의 브라우저에서 주사위 1억 회는 기존 약 11초에서 약 2.8초로 줄었습니다. 기기별 차이가 있으며 100억 회 전체 완료 시간은 실측하지 않았습니다. 병렬 합산이나 분포 근사로 시행을 대체하지 않습니다.

윷은 네 막대가 독립이라는 단순화 모형이며 실제 윷의 측정 자료가 아닙니다. 쿠폰 실험 1회는 모든 종류를 모을 때까지 뽑는 전체 과정입니다.
